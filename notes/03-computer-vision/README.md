## Manual — secção 13

Multimodal understanding: modelo interpreta imagem + texto e responde de forma flexível.
Image/video generation: cria ou edita media; inclui inpainting, masks e reference media conforme modelo.
Content Understanding: converte media/documentos em estrutura previsível usando analyzers e schemas.
OCR/layout: componentes de extração; Content Understanding pode combiná-los com reasoning multimodal.
Visual safety: unsafe content, watermark/policy e indirect prompt injection por texto na imagem.
Distinção essencial — Multimodal model = “entende e raciocina sobre o que vê”. Content Understanding = “extrai, de forma estruturada, os campos que a aplicação definiu”. Image generation = “cria/edita media”.
